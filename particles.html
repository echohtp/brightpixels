Renderer status does not measure physical brightness. Actual HDR depends on your browser, display and settings. Reduced motion uses stationary sparkles. The fallback caps active particles at 256.

import { createParticleEffects } from 'brightpixels/particles';

const effects = createParticleEffects({ intensity: 8 });
await effects.ready;
effects.burst({ x: 300, y: 300, count: 120 });
const stopTrail = effects.trail(document.querySelector('.stage'));
